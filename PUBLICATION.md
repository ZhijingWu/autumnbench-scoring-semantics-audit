# Publication scope

The original frozen study remains unchanged in its research archive. This repository is a selected publication edition: private paths are redacted, some JSON/JSONL are gzip-packed, external dependencies are acquired separately, and portability edits are documented in provenance/source_map.json. Original hashes identify the historical bytes; PUBLIC_MANIFEST.json binds the public bytes. No new scientific inference, GPU experiment or paid API call was performed for publication.

Read-only reproduction uses a temporary work directory and leaves the published results untouched. Full neural/native/learning reruns require the documented external assets and a fresh output root. Archive preservation checks and public-edition integrity checks have distinct scopes.
